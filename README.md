Caesar Cipher — Task 01
Implementation of Caesar Cipher Encryption and Decryption using Python

✨ About the Project
This project was completed as part of the Prodigy Infotech Internship Program.
The objective was to implement the Caesar Cipher encryption technique where each character of the plaintext is shifted by a fixed number of positions.

📌 Features
Encrypts user-inputted text based on a shift value.

Decrypts encrypted text back to original form.

Preserves spaces, numbers, and special characters.

Supports both uppercase and lowercase alphabets.

Modular Arithmetic
